# AdGest UY

Web app para conectar despachantes con gestores en un flujo de trabajo de despacho aduanero y logística.

## Stack

- React + Vite
- React Router v6
- Tailwind CSS
- Context API (sin backend — datos mock)

## Roles

- **Despachante**: crea tareas desde DUAs, las asigna a gestores, controla el estado
- **Gestor**: ejecuta las tareas asignadas, actualiza el progreso, chatea con el despachante
